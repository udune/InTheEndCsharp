## 메시지
- `;이 필요합니다.` (CS1002) / ; expected
- `}가 필요합니다.` (CS1513) / } expected
- `)가 필요합니다.` (CS1026) / ) expected

## 원인
```csharp
int x = 1                       // CS1002: 문장 끝에 ; 빠짐
if (x > 0 { }                   // CS1026: ) 빠짐
void M() { if (ok) { }          // CS1513: 닫는 } 부족
```

## 찾는 요령
- 컴파일러는 **문제가 드러난 곳**을 가리킵니다. 실제로 빠뜨린 곳은 **바로 윗줄**인 경우가 많습니다.
- 중괄호 하나가 빠지면 파일 아래쪽 전체에서 오류가 **수십~수백 개** 쏟아질 수 있습니다. 첫 번째 오류부터 고치고 다시 빌드하세요.
- IDE에서 `{`에 커서를 두면 짝이 되는 `}`가 강조됩니다. 코드 정리(`Ctrl + K, Ctrl + D`)로 들여쓰기를 맞추면 짝이 안 맞는 곳이 잘 보입니다.
- 문자열의 따옴표를 닫지 않으면(`"abc`) 뒤의 코드 전체가 문자열로 인식됩니다.
