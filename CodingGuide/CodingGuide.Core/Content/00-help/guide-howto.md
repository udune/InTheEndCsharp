## 무엇을 할 수 있나요?
- **개념 찾기**: "제네릭 제약 조건", "델리게이트", "lock"
- **하고 싶은 일로 찾기**: "리스트에서 중복 제거", "천 단위 콤마", "파일 읽기", "몇 초마다 실행"
- **오류 메시지로 찾기**: 오류 창의 메시지를 그대로 붙여 넣으세요. "개체 참조가 개체의 인스턴스로 설정되지 않았습니다", "CS0103"
- **예제 실행**: 학습 예제가 연결된 문서는 [▶ 예제 실행]으로 실제 출력을 볼 수 있습니다.

## 화면 구성
- **왼쪽**: 검색창과 결과 목록. 검색창이 비어 있으면 전체 목차가 보입니다.
- **오른쪽 위**: 설명 문서
- **오른쪽 아래 탭**: [예제 코드] 원본 소스 / [실행 결과] 예제 실행 출력

## 검색 요령
- 문장으로 물어봐도 됩니다: "여러 스레드가 같은 변수를 바꾸면 값이 이상해요"
- 영어 키워드도 됩니다: "Where", "Dictionary", "async" (오타도 어느 정도 보정됩니다)
- 결과가 많으면 단어를 더 구체적으로: "정렬" → "리스트 내림차순 정렬"
- 문서 하단의 **관련 문서**를 따라가면 연결된 개념을 이어서 볼 수 있습니다.

## 단축키
- `Ctrl + F` 또는 `Ctrl + L`: 검색창으로 이동
- `Esc`: 검색어 지우고 목차 보기
- `↑` `↓`: 검색 결과 이동, `Enter`: 선택
- `F5`: 현재 문서의 예제 실행
- `Alt + ←`: 이전 문서로 돌아가기
